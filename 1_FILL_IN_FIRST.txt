HOMELAB DASHBOARD - QUESTIONS TO FILL IN FIRST
==============================================

HOW TO USE THESE 2 FILES
1. In Claude, create a Project (for example "Homelab Dashboard").
   Tip from experience: every conversation about the dashboard then stays in the same
   place, Claude keeps the context from one chat to the next, and it is much easier to
   follow the work over days and weeks.
2. Fill in this file (write your answers after each question).
3. Paste the content of 2_PROMPT_FOR_CLAUDE.txt in the Project instructions.
4. Add this file, once filled in, to the Project knowledge.
5. Start a new chat in the Project and write: "Read my answers and propose the first step."

Never write passwords, tokens or API keys in this file or in the chat.
